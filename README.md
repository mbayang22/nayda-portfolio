# NAYDA — Portfolio de Ndeye Aida Sambe

Site statique HTML/CSS/JS, prêt pour Vercel (Framework Preset : Other, pas de build).

## Logo
Placer le logo fourni dans `assets/images/logo-nayda.png` : il remplace automatiquement le texte NAYDA dans l'en-tête (proportions conservées).

## Noms des collections / créations
Sous chaque photo, la ligne grise `NOM DE LA COLLECTION · Année · Matière / technique` (ou `NOM DE LA CRÉATION …`) est un emplacement libre : la remplacer dans `index.html` par les vraies informations.
Dans la galerie, le nom affiché en grand s'ajoute avec `data-name="Nom · 2024 · Matière"` sur le bouton `gallery-tile`.

## Photos
Toutes dans `assets/images/` (cover, motif-*, couleurs, textile-*, collection-*, recycle-*, final-*).
